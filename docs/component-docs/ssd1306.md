# SSD1306 OLED (ssd1306)
Status: complete
Wokwi tag: wokwi-ssd1306

## Pins
| pin | role | typical connection |
|---|---|---|
| DATA | I2C data line (SDA) | A4 on Uno, GPIO 21 on ESP32 |
| CLK | I2C clock line (SCL) | A5 on Uno, GPIO 22 on ESP32 |
| VIN | Supply voltage | 5V on Uno, 3V3 on ESP32 |
| 3V3 | Regulated 3.3V output (module side) | none (available for other parts) |
| GND | Ground | GND |

## Attributes
| attribute | type | default | role |
|---|---|---|---|
| i2cAddress | string | '0x3c' | I2C address of the display |
| imageData | string | None | image shown on the display, if set |

## Wiring
- Arduino Uno: VIN -> 5V, GND -> GND, DATA -> A4, CLK -> A5
- ESP32: VIN -> 3V3, GND -> GND, DATA -> GPIO 21, CLK -> GPIO 22

## Minimal sketch
Not compiled.
```cpp
// SSD1306 128x64 OLED over I2C: print a title and the uptime
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#define SSD1306_ADDR 0x3C
Adafruit_SSD1306 display(128, 64, &Wire, -1);
void setup() {
  Serial.begin(115200);
  if (!display.begin(SSD1306_SWITCHCAPVCC, SSD1306_ADDR)) {
    Serial.println("SSD1306 not found");
    while (true) delay(10);
  }
}
void loop() {
  display.clearDisplay();
  display.setTextSize(2);
  display.setCursor(0, 0);
  display.print("Hello");
  display.setTextSize(1);
  display.setCursor(0, 24);
  display.print("uptime: ");
  display.print(millis());
  display.display();
  delay(200);
}
```

## Pitfalls
- This part is deprecated by Wokwi: board-ssd1306 is the recommended replacement. The simulation is I2C only, so the DC/RST/CS (SPI) pins are not functional.
- Default address is 0x3C, some modules use 0x3D: scan the bus if begin() fails. Feed VIN from 5V (Uno) or 3V3 (ESP32); the 3V3 pin is an output, not an input.
