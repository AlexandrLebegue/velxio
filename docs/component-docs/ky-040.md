# KY-040 Rotary Encoder (ky-040)
Status: complete
Wokwi tag: wokwi-ky-040

## Pins
| pin | role | typical connection |
|---|---|---|
| CLK | Encoder pin A (quadrature) | Pin 2 on Uno, GPIO 2 on ESP32 |
| DT | Encoder pin B (quadrature) | Pin 3 on Uno, GPIO 3 on ESP32 |
| SW | Push button, normally open to GND | Pin 4 with pull-up |
| VCC | Voltage supply | 5V on Uno, 3V3 on ESP32 |
| GND | Ground | GND |

## Attributes
| attribute | type | default | role |
|---|---|---|---|
| angle | number | 0 | current knob angle in degrees |
| stepSize | number | 18 | degrees per step (20 steps per revolution) |
| pressed | boolean | False | state of the shaft push button (SW) |

## Wiring
- Arduino Uno: VCC -> 5V, GND -> GND, CLK -> pin 2, DT -> pin 3, SW -> pin 4
- ESP32: VCC -> 3V3, GND -> GND, CLK -> GPIO 2, DT -> GPIO 3, SW -> GPIO 4

## Minimal sketch
Not compiled.
```cpp
// KY-040: count steps on CLK/DT quadrature, SW resets the counter
#define PIN_CLK 2
#define PIN_DT 3
#define PIN_SW 4
int position = 0, lastClk = HIGH;
void setup() {
  Serial.begin(115200);
  pinMode(PIN_CLK, INPUT_PULLUP);
  pinMode(PIN_DT, INPUT_PULLUP);
  pinMode(PIN_SW, INPUT_PULLUP);
  lastClk = digitalRead(PIN_CLK);
}
void loop() {
  int clk = digitalRead(PIN_CLK);
  if (clk != lastClk) {
    lastClk = clk;
    if (clk == LOW) {
      position += (digitalRead(PIN_DT) == HIGH) ? 1 : -1;
      Serial.println("position: " + String(position));
    }
  }
  if (digitalRead(PIN_SW) == LOW) position = 0;
}
```

## Pitfalls
- The module has internal pull-ups on CLK and DT (kept in the simulator even if VCC floats): read SW with INPUT_PULLUP, it is LOW while pressed.
- Simulator timing: clockwise makes CLK go LOW before DT, so on a CLK falling edge DT HIGH = clockwise, DT LOW = counterclockwise.
- Both encoder pins stay LOW only a few milliseconds per step: poll them fast or use attachInterrupt() on CLK, or steps are lost.
