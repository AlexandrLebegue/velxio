# A4988 Stepper Driver (a4988)
Status: complete
Wokwi tag: velxio-a4988

## Pins
| pin | role | typical connection |
|---|---|---|
| STEP | step input from the microcontroller | Uno 3 / ESP32 GPIO 26 |
| DIR | direction input: 0 = counterclockwise, 1 = clockwise | Uno 4 / ESP32 GPIO 27 |
| ENABLE | output enable, active low (pulled low by default) | tied to the supply to enable the driver |
| RESET | reset, active low (floating by default) | tied to SLEEP (pulled high by default) |
| SLEEP | sleep mode, active low (pulled high by default) | supply, or an MCU pin to disable the driver |
| MS1, MS2, MS3 | microstep select, latched at power-on | GND/supply combinations from the mode table |
| 1A | coil pair 1 output | motor B+ |
| 1B | coil pair 1 output | motor B- |
| 2A | coil pair 2 output | motor A+ |
| 2B | coil pair 2 output | motor A- |
| VDD | logic power supply (3 to 5V) | 5V on Uno, 3V3 on ESP32 |
| VMOT | motor power supply (8 to 35V), not used in the simulation | external motor supply on real hardware |
| GND | ground | GND (common with the MCU and the motor supply) |

## Attributes
| attribute | type | default | role |
|---|---|---|---|
| (none) | - | - | this part has no configurable attributes |

## Wiring
- Arduino Uno: STEP -> 3, DIR -> 4, ENABLE -> 5V, RESET -> SLEEP, GND -> GND, VDD -> 5V, 1A -> motor B+, 1B -> motor B-, 2A -> motor A+, 2B -> motor A-
- ESP32: STEP -> GPIO 26, DIR -> GPIO 27, ENABLE -> 3V3, RESET -> SLEEP, GND -> GND, VDD -> 3V3, 1A -> motor B+, 1B -> motor B-, 2A -> motor A+, 2B -> motor A-

## Minimal sketch
Not compiled.
```cpp
// A4988 in full-step mode (MS1-3 low): STEP on pin 3, DIR on pin 4 (Uno)
// ENABLE is tied to 5V and RESET is tied to SLEEP on the board.
#include <AccelStepper.h>
AccelStepper motor(DRIVER, 3, 4); // DriverMotorType: STEP and DIR pins
void setup() {
  Serial.begin(115200);
  Serial.println("A4988 driver ready");
  motor.setMaxSpeed(1000); // max speed in steps per second
  motor.setAcceleration(200);
}
void loop() {
  motor.moveTo(motor.currentPosition() + 200); // one turn per pass
  motor.run(); // call as often as possible to reach the target
}
```

## Pitfalls
- ENABLE is active low and pulled low by default in the simulator: without tying it to the supply, the driver stays disabled.
- RESET is active low and floating by default: the usual fix is to wire RESET to SLEEP, which is pulled high by default.
- The MS1/MS2/MS3 microstepping configuration is latched when power is applied: set those pins before powering the driver.
- On real hardware VMOT needs 8 to 35V for the motor and VDD 3 to 5V for the logic; Wokwi ignores VMOT in the simulation.
