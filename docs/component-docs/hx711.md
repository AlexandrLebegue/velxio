# HX711 (hx711)
Status: complete
Wokwi tag: wokwi-hx711

## Pins
| pin | role | typical connection |
|---|---|---|
| VCC | voltage supply (5V) | 5V on Uno, 3V3 on ESP32 |
| DT | serial data output from the ADC | analog input pin (A1 in the Wokwi example) |
| SCK | serial clock output from the microcontroller | analog input pin used as output (A0 in the Wokwi example) |
| GND | ground | GND |
| E+, E-, A+, A-, B+, B- | load cell bridge pads, rendered only (non-interactive) | none, drawn based on the type attribute |

## Attributes
| attribute | type | default | role |
|---|---|---|---|
| type | string | '50kg' | scale type: '50kg', '5kg' or 'gauge' |

## Wiring
- Arduino Uno: DT -> A1, SCK -> A0, VCC -> 5V, GND -> GND
- ESP32: DT -> GPIO 32, SCK -> GPIO 33, VCC -> 3V3, GND -> GND

## Minimal sketch
Not compiled.
```cpp
// HX711 load cell scale: DT on A1, SCK on A0 (Uno)
#include "HX711.h"
HX711 scale;
void setup() {
  Serial.begin(115200);
  Serial.println("Initializing the scale");
  scale.begin(A1, A0); // data pin first, clock pin second
  scale.set_scale(1000); // calibration factor, tune for your cell
  scale.tare(); // zero the scale at startup
}
void loop() {
  Serial.println(scale.get_units(10), 2); // average of 10 readings
  delay(1000);
}
```

## Pitfalls
- begin() takes the DT (data) pin first and the SCK (clock) pin second; swapping them gives garbage readings.
- The simulated chip has no channel B and no 32/64/128 gain options; raw readings are 0 to 2100 for type '5kg' and 0 to 21000 for '50kg'.
- The bridge pads (E+/E-/A+/A-/B+/B-) are not interactive: the load is set through the type attribute and the automation 'load' control (kg).
- The HX711 library is required; readings are noisy, so average several samples with get_units(n).
