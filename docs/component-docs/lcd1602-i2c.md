# LCD 16x2 (I2C) (lcd1602-i2c)
Status: complete
Wokwi tag: wokwi-lcd1602

## Pins
| pin | role | typical connection |
|---|---|---|
| SDA | I2C data line | A4 on Uno, GPIO 21 on ESP32 |
| SCL | I2C clock line | A5 on Uno, GPIO 22 on ESP32 |
| VCC | Supply voltage | 5V on Uno, 3V3 on ESP32 |
| GND | Ground | GND |

## Attributes
| attribute | type | default | role |
|---|---|---|---|
| pins | string | 'full' | 'i2c' for the I2C configuration (this part), 'full' for standard 7-wire |
| i2cAddress | string | '0x27' | I2C address of the PCF8574T backpack |
| color | string | 'black' | text color |
| background | string | 'green' | backlight color |
| variant | string | 'A00' | built-in font variant: "A00" or "A02" |

## Wiring
- Arduino Uno: VCC -> 5V, GND -> GND, SDA -> A4, SCL -> A5
- ESP32: VCC -> 3V3, GND -> GND, SDA -> GPIO 21, SCL -> GPIO 22

## Minimal sketch
Not compiled.
```cpp
// LCD 16x2 with PCF8574 backpack: two-line status over I2C
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);
void setup() {
  Serial.begin(115200);
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Hello World");
}
void loop() {
  lcd.setCursor(0, 1);
  lcd.print("t=");
  lcd.print(millis() / 1000);
  lcd.print("s     ");
  delay(1000);
}
```

## Pitfalls
- Set the pins attribute to "i2c" on the wokwi-lcd1602 part: its default "full" is the standard 7-wire configuration (RS/E/D4-D7), not the I2C backpack.
- The I2C side is a PCF8574T expander, not the LCD itself: use the LiquidCrystal_I2C library, and scan the bus if it answers on another address.
- The backlight is driven by the backpack (P3), so the library turns it on with lcd.backlight(); no extra wiring is needed.
