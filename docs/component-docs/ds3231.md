# DS3231 RTC (ds3231)
Status: complete
Wokwi tag: velxio-ds3231

## Pins
| pin | role | typical connection |
|---|---|---|
| SDA | I2C data line | A4 on Uno, GPIO 21 on ESP32 |
| SCL | I2C clock line | A5 on Uno, GPIO 22 on ESP32 |
| VCC | supply voltage (3.3V to 5V) | 3V3 on Uno and ESP32 |
| GND | ground | GND |

## Attributes
| attribute | type | default | role |
|---|---|---|---|
| temperature | number | 25 | temperature in degrees C from the built-in sensor |

## Wiring
- Arduino Uno: VCC -> 3V3, GND -> GND, SDA -> A4, SCL -> A5
- ESP32: VCC -> 3V3, GND -> GND, SDA -> GPIO 21, SCL -> GPIO 22

## Minimal sketch
Not compiled.
```cpp
// DS3231 RTC (I2C address 0x68): print the time and the internal temperature
#include <Wire.h>
#define ADDR 0x68
uint8_t bcd(uint8_t v) { return (v & 0x0F) + (v / 16) * 10; } // BCD to binary
void setup() {
  Serial.begin(115200);
  Wire.begin(); // A4/A5 on Uno, GPIO 21/22 on ESP32
}
void loop() {
  Wire.beginTransmission(ADDR);
  Wire.write(0x00); // start at the seconds register
  Wire.endTransmission(false);
  Wire.requestFrom(ADDR, 7);
  uint8_t s = bcd(Wire.read() & 0x7F); // seconds
  uint8_t m = bcd(Wire.read() & 0x7F); // minutes
  uint8_t h = bcd(Wire.read() & 0x3F); // hours
  Wire.read(); // skip day of week
  Serial.println(String(h) + ':' + String(m) + ':' + String(s));
  Wire.beginTransmission(ADDR);
  Wire.write(0x11); // temperature register
  Wire.endTransmission(false);
  Wire.requestFrom(ADDR, 1);
  Serial.println("temp: " + String(Wire.read() * 0.25) + " C");
  delay(1000);
}
```

## Pitfalls
- The I2C address is fixed at 0x68 and VCC accepts 3.3V to 5V; on the ESP32 use the 3V3 rail so the I2C levels match.
- The built-in temperature sensor is read from register 0x11 with 0.25 degrees C per step; it indicates the module ambient, not a precision thermometer.
- It keeps the same time registers (0x00 to 0x06) as the DS1307, but runs from 3.3V where a DS1307 needs about 4.5V, so DS1307-style code can read it directly.
