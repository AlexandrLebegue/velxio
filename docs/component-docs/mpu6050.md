# MPU6050 (mpu6050)
Status: complete
Wokwi tag: wokwi-mpu6050

## Pins
| pin | role | typical connection |
|---|---|---|
| VCC | Power supply (3.3V to 5V) | 5V on Uno, 3V3 on ESP32 |
| GND | Ground | GND |
| SCL | I2C clock line | A5 on Uno, GPIO 22 on ESP32 |
| SDA | I2C data line | A4 on Uno, GPIO 21 on ESP32 |
| AD0 | Address select: 0x68 (floating) or 0x69 (tied to VCC) | left floating, or VCC for a second sensor |

## Attributes
| attribute | type | default | role |
|---|---|---|---|
| accelX | number | 0 | initial x acceleration (g) |
| accelY | number | 0 | initial y acceleration (g) |
| accelZ | number | 1 | initial z acceleration (g) |
| rotationX | number | 0 | initial x rotation (deg/s) |
| rotationY | number | 0 | initial y rotation (deg/s) |
| rotationZ | number | 0 | initial z rotation (deg/s) |
| temperature | number | 24 | initial temperature (celsius) |

## Wiring
- Arduino Uno: VCC -> 5V, GND -> GND, SCL -> A5, SDA -> A4
- ESP32: VCC -> 3V3, GND -> GND, SCL -> GPIO 22, SDA -> GPIO 21

## Minimal sketch
Not compiled.
```cpp
// MPU6050 6-axis IMU over I2C: stream accel, gyro, temperature
#include <Wire.h>
#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>
Adafruit_MPU6050 mpu;
void setup() {
  Serial.begin(115200);
  Wire.begin();
  while (!mpu.begin()) delay(1000);
  Serial.println("MPU6050 ready");
}

void loop() {
  sensors_event_t a, g, t;
  mpu.getEvent(&a, &g, &t);
  Serial.printf("A: %.2f %.2f %.2f m/s2\n", a.acceleration.x, a.acceleration.y, a.acceleration.z);
  Serial.printf("G: %.1f %.1f %.1f dps  T: %.1f C\n", g.gyro.x, g.gyro.y, g.gyro.z, t.temperature);
  delay(500);
}
```

## Pitfalls
- I2C address is 0x68 by default; tie AD0 to VCC to get 0x69 for a second sensor on the same bus.
- Requires the Adafruit MPU6050 library (with Adafruit Unified Sensor); on the ESP32 call Wire.begin(21, 22) instead of Wire.begin().
- XDA/XCL exist on the module but are not implemented in the Wokwi simulator; INT (active low) is listed by Wokwi but unused here.
