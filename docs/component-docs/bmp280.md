# BMP280 (Pressure + Temp) (bmp280)
Status: complete
Wokwi tag: velxio-bmp280

## Pins
| pin | role | typical connection |
|---|---|---|
| VCC | Supply (3.0-3.6V) | 3V3 from the board |
| GND | Ground | GND |
| SDA | I2C data | I2C SDA (e.g. A4 on the Uno) |
| SCL | I2C clock | I2C SCL (e.g. A5 on the Uno) |

## Attributes
| attribute | type | default | role |
|---|---|---|---|
| temperature | number | 24 | Simulated temperature (C), -40 to 85 range |
| pressure | number | 1013.25 | Simulated pressure (hPa), 300 to 1100 range |

## Wiring
- Arduino Uno: VCC -> 3V3, GND -> GND, SDA -> A4, SCL -> A5
- ESP32: VCC -> 3V3, GND -> GND, SDA -> GPIO 21, SCL -> GPIO 22

## Minimal sketch
Not compiled.
```cpp
// BMP280: read barometric pressure and temperature over I2C
#include <Adafruit_BMP280.h>
#include <Wire.h>

Adafruit_BMP280 bmp;

void setup() {
  Serial.begin(115200);
  Wire.begin();
  if (!bmp.begin(0x76)) {
    Serial.println("BMP280 not found");
    while (true) {
    }
  }
}

void loop() {
  Serial.print("Pressure hPa: ");
  Serial.print(bmp.readPressure() / hPa);
  Serial.print("  Temp C: ");
  Serial.println(bmp.readTemperature());
  delay(2000);
}
```

## Pitfalls
- I2C address is 0x76 by default, 0x77 when the SDO pin is tied to VDD: check the module's SDO jumper before debugging.
- VCC takes 3.0-3.6V only: never feed 5V; on real hardware the Uno's 5V I2C bus exceeds the chip's 3.6V-tolerant I/O (use 3.3V pull-ups or a level shifter).
- On the ESP32 call Wire.begin(21, 22) if you use pins other than the 21/22 default.
- In the simulator the values are live-editable from the sensor panel (temperature, pressure sliders).
